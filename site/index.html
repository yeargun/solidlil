Tree-shaking is the fair size

Tree shaking remains enabled on both sides. The audit also rebuilds the same Solid entry with Vite tree shaking disabled. That moves Solid from 11,255 B to 12,705 B Brotli, so Vite's tree-shaking step accounts for 1,450 B. The remaining gap still combines LilScript's stronger whole-program DCE with runtime representation; this app comparison cannot separate those effects.

Tooling

LilScript, LSX, this page

  1. LilScript is the language and compiler. It types the program, then searches JS spellings against Brotli. Owned aggregates can be positional. That compiler lives in yeargun/lilscript — see why it beats minifying harder and mangle / ABI.
  2. LSX (.lilx) is JSX for LilScript. parse-jsx.mjs reads the markup; lower.mjs emits cloneTemplate plus For / Show calls into lsx.lil. Same idea as Solid’s JSX → template().cloneNode(true).
  3. This lab pairs each Solid 2.0 Vite app with the LSX compile of the same UI. The hero uses the tracked JFB-compatible pair and the canonical shared-minifier row. The grid remains closed-world examples; do not sum it into a framework payload.
